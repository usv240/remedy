Part of the [Remedy README](../README.md). Ten claims the README makes, each with where to see it on the live site, the file and line in this repo that does it, and the test that checks it. Line numbers were checked against the code on November 9, 2026, and `tests/evidence-index.test.ts` fails when a path or line here no longer matches. "Needs keys" means PayPal sandbox keys; everything else runs with a bare `npm test`.
